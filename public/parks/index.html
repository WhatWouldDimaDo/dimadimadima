About the data

Every amenity flag on this site carries its own evidence: a quote from a real source, a link, and a confidence level. If we couldn't prove it, it says unknown — never a guess.

high
an official page (city / county / state DOT) states it outright
med
an official list omits it, or a review / blog / structured map source states it
? unknown
no source found — an honest gap, not a hidden "no"
HAND-VERIFIED
full amenity record built and source-checked by hand
MAPPED
found on the map, not yet enriched — amenities still unknown

Detour times are straight-line distance × 1.3 road factor — routed drive times land with the next enrichment pass. Satellite thumbnails and map imagery © Esri. Map data © OpenStreetMap contributors.
